# 系統設定、百科與計算器

[返回機制索引](README.md)

這裡說明介面上不涉及角色狀態的部分：系統頁的連接與追蹤設定、百科的參數覆寫，以及計算器。連接、主題與追蹤開關仍是全域偏好；v1.1.3 起，世界設定也可存在角色卡上，角色狀態則每個對話各存一份。

## 角色卡世界設定

百科上方的「編輯範圍」可選全域或目前角色卡。物種、衍生類型與生殖基準採 **卡片 > 全域 > 內建** 逐欄位合併：卡片只改胚型時，全域的其他參數仍然生效。名錄與世界基準則整份取代，卡片的空名錄或空基準也是明確設定。

編輯器顯示所選範圍的值與來源；資料頁和實際計算使用合併後的結果。清除卡片物種／衍生覆寫，或在基準頁按「清除卡片基準覆寫」，會沿用全域。清除全域覆寫不會刪卡片設定。種子、物種覆寫與其他擴充資料也不會因清除基準而被刪除。

綁卡資料存在 `data.extensions.bs_biotracker`，隨宿主匯出角色卡傳遞。群聊忽略卡片設定；宿主沒有寫卡介面時隱藏卡片編輯選項，仍可讀取已附帶的設定。API 金鑰、主題、系統開關與角色狀態不會存進這個欄位。

承載耐受等註冊時寫入的角色參數不會因編輯卡片而自動重算，腹中胎兒保留受孕時的胚型；後續受孕與即時計算才使用新設定。

介面上各處的「?」會在插件裡直接打開這些說明並跳到對應章節，讀的是隨插件安裝的 `docs/`，離線也能看；閱讀器右上角的 ↗ 改到 GitHub 開啟，文件裡指向程式碼的連結也一律開 GitHub。[說明閱讀器](../../scripts/doc_viewer.js#L1)。

## 系統頁

### 連接設定

- **API Base URL、API 格式、API Key、模型名稱**：追蹤、註冊與各種推演共用同一組連接。輸入網址時下方會預覽實際請求的端點。API 格式決定請求送到 `/chat/completions`、`/responses`、`/messages` 或 `/interactions`；非相容格式在 TauriTavern 由宿主後端翻譯，在原版 SillyTavern 走 `/proxy/` 透傳。
- **連接並拉取模型**：向端點要模型清單，選了會填進模型名稱。切換配置組後舊清單會清空，需要時再拉一次。
- **連接配置組**：把分隔線以上的整段連接設定（網址、格式、Key、模型、溫度、思考強度、格式化輸出）以名稱存成一組，最多 30 組，同名覆蓋前會確認；從下拉選一組即套用並保存。下拉只顯示名稱，不顯示 Key。Key 與其他設定一樣存在本機的 SillyTavern 設定檔。[配置組](../../scripts/state.js#L869)。

### 溫度、思考強度、格式化輸出

- **溫度**：三種模式。「沿用舊行為」是過去的邏輯（主請求 0.2、重試 0.1，預設可覆蓋）；「不傳參數」給要求省略 temperature 的模型；「手動指定」每次都用你填的值，也會覆蓋預設。[溫度](../../scripts/state.js#L148)。
- **思考強度**（`reasoning_effort`）：Minimal 到 Max；預設 Auto 不傳這個參數，由服務端決定。小尺寸模型拉高思考強度有助於輸出正確。[思考強度](../../scripts/state.js#L138)。
- **格式化輸出**：請求附加 `response_format.type = json_object`，能減少掉格式；渠道不支援這個參數時要關掉。[格式化輸出](../../scripts/api.js#L55)。
- **主線複製字數上限**（預設 40 萬字，0 為不限）：世界書模式為「主流模式」時，追蹤請求會複製主線上一輪的系統訊息與最近訊息。主線的上下文上限可能遠大於追蹤 API 的上限，strict 提示後處理又會把整份系統內容合併成一則，所以只限則數擋不住。超過這個字數時先由舊到新略去複製來的聊天訊息，仍超過才從系統訊息尾端截斷並註明截斷字數，同時跳出提示。這個值會一併存進 API 配置組，跟著那組 API 的上下文大小走。[主線複製上限](../../scripts/api.js#L803)。

### 追蹤節奏

- **觸發時機**：自動追蹤一律在 AI 回覆定稿後進行。舊版另有使用者一送出就追蹤的 `after_user`，但那時主線已經組好提示、正在生成，追蹤結果趕不上這一輪，AI 這輪寫的事也要等下次送出才記錄，所以移除；舊設定載入時自動清掉這個選項。
- **輪詢間隔、請求逾時、送入分析的最近訊息數**：控制多久檢查一次新訊息、單次請求最長等多久（0 表示不限）、每次追蹤附上幾則近期對話。
- **追蹤提示詞注意力預算**：估算追蹤請求的 token 數，只用來讓左上角的電池顯示請求體積，**不會限制或截斷送出的內容**。

### 功能開關

- **子宮圖待機動畫**：關閉後只畫靜態圖；事件特寫仍會播一次，系統設定為減少動態效果時則不播。
- **著衣系統、技能系統**：關閉後對應的頁面與註冊分頁隱藏，追蹤模型看不到相關工具、說明與狀態；已有的衣櫃與技能資料原樣保留，重新開啟即恢復。[開關](../../scripts/state.js#L902)、[工具過濾](../../scripts/tracker.js#L710)。
- **Luker 多智能體安全模式**：在 Luker 上關閉自動追蹤，等編排完成後手動分析。
- **送入分析的單角色最近日記數**：設 0 等於關閉日記系統。

## 百科

### 物種與衍生類型的參數覆寫

- 「調整參數」可以覆寫一個物種的生理數值、遺傳核型、胚型、產後恢復係數與物種短敘述，衍生類型則可覆寫短敘述、Flux 定義與繼承速度。
- 只保存與內建值不同的欄位；「恢復內置」清掉這個物種的全部覆寫，「套用人類預設值」把編輯器填成人類的內建數值。人類也能像其他物種一樣調整參數與短敘述；各參數說明裡「以人類為 1」的比較基準（經期 28 天、孕期 280 天、產後 56 天）固定採用人類預設值，不隨人類的覆寫改變。
- 物種短敘述（程式欄位 `introductionLine`）每族只有一欄，用在兩處：該物種有角色在場時，整句隨生理說明送出；註冊時的物種名錄只截取開頭一兩個分句當辨識提示（到第一個句號或分號為止，約 10–28 字，至少含一句中文），後面接「級數·體態」。編輯器在欄位下方即時預覽名錄會截取到哪裡，最能辨認形象的描述要寫在最前面。
- 混血種族一律按一般核型處理；衍生類型的代謝抵免維持內建規則，子項繼承所屬的衍生大類。
- 覆寫存在 SillyTavern 的設定檔裡，重裝插件不會清除。「已保存的參數覆寫」清單也會列出名錄裡已經選不到的條目（例如早期版本覆寫過的人類），可以逐項或整批清除。[覆寫套用](../../index.js#L1816)、[覆寫清單](../../index.js#L2523)、[物種覆寫](../../scripts/race_config.js#L1152)、[衍生覆寫](../../scripts/race_config.js#L1053)。
- 胚型、恢復係數這類在受孕、分娩當下才查的值，改了立刻生效；承載耐受等在註冊時寫進角色的值，只影響之後註冊的角色。

### 物種體型

- 每個物種有三個體型欄位，可在「調整參數」覆寫：
  - **體型**：1–7 級，人類為 4（1 掌上、2 矮小、3 偏小、4 人類、5 高大、6 巨大、7 巨獸）。能變形的物種記常態（人態），多數是 4；西方龍、海德拉、空鯨的人態高大（5），麒麟、獨角獸嬌小（3）。另有兩種特殊值：**可變**表示能隨對象調整形體，與任何對象都恰好契合（史萊姆、偽人等）；**依個體**表示大小固定、但同族差異大到給不出單一數字，要依子項或個體判斷（怪獸類、植物族、真菌族等）。
  - **體型標準差**：族內個體的差異，以「級」計，人類 0.4，約等於 120–220 cm 的極端範圍。
  - **變化態體型**：變形後的大小，例如龍的真身 7、妖精以魔法變成人類大小的 4。沒有變化態就是「無」。
- 混血依血統比例加權平均體型；可變與依個體的成分不參與，但父母若是依個體種族且記有個體體型（例如一人高的大蟑螂），就以那個值參與。標準差除了各族的差異，還加上各族平均體型的落差，所以巨人與半身人的混血可能長成 2 到 6 級。只要有一個成分有變化態，混血就有變化態，沒有變化態的成分以常態體型參與加權（半龍半人的變化態為 5.5）。[混血體型](../../scripts/race_config.js#L1588)。
- **個體體型**：角色身上的 `base.bodySize`，記常態，一位小數。註冊模型依角色卡寫的身高或身材換算（約 120 cm＝2.5、170 cm＝4、220 cm＝5、八尺約 5.3）；卡上沒寫就按種族分布抽一次，孩子註冊時代入已知父母的體型。可變種族留空；依個體種族沒給就標「未記錄」。舊角色沒有這個欄位時一律以種族平均計算，不補抽。變化態體型 = 種族變化態 +（個體 − 種族平均），截在 1–7：比族人高大的龍娘，真身也比較大。追蹤頁的角色概覽會顯示體型。[抽樣與變化態](../../scripts/body_size.js#L62)、[註冊抽樣](../../scripts/registry.js#L1860)。
- **體型契合**：`bsAddSperm insert` 按雙方當下的體型結算，存在 `base.penetrationFit`，拔出時清除。精方依序看已註冊角色、本次的 `maleBodySize`、種族平均；依個體種族又沒給體型時不結算。追蹤提示另送一段依當前生效資料（含百科覆寫）產生的依個體物種名單，提醒插入時要傳 `maleBodySize`，未收錄的自訂種族也要傳；寫實世界不送。`femaleAltForm`／`maleAltForm` 改用變化態計算，`sizeBridge` 表示以魔法、變形消弭體型差、視為恰好契合。體型差分段：不到 0.5 級恰好契合；0.5–1.5 略有落差；1.5–2.5 明顯不合；2.5–4 極不相稱；4 級以上體型懸殊，再依哪一方較大寫成「需要適應／伴隨不適／極難容納」或「略嫌不足／難以充實／幾乎感受不到」。不到 0.5 級又沒變身時只寫進回傳訊息，否則另進次級提示給主線。[體型契合](../../scripts/tools.js#L7130)、[分段](../../scripts/body_size.js#L120)。
- **父方體型**：射精時，個體體型已知的精源（已註冊角色或插入時給過 `maleBodySize`）會記在精液紀錄上，受孕時存進胎兒的 `fatherBodySize`，出生後帶到孩子身上；精液清掉後仍查得到父方多大。族譜詳情也會顯示：已註冊角色顯示個體體型（沒有就標種族平均），未註冊的路人父親在子女記錄有體型時顯示並註明「據子女記錄」。
- **受精胎重**：受精當下的胎重係數，雙方體型都有數值時看體型差：2^((父方 − 承載者) × 0.25)，截在 0.5–2，巨人父親懷在人類體內約 1.41 倍、半身人懷巨人約 2 倍，胎重較大也就較難分娩。胎兒大小主要受母體子宮限制（馬的雜交實驗如此），所以父方體型只部分影響。任一方可變、或依個體種族沒記體型時，改用承載耐受的強弱 2^強弱（強弱介於 −1 與 1），同樣在 0.5–2；兩套不疊加。代孕時看承載者。[胎重係數](../../scripts/tools.js#L1334)、[體型係數](../../scripts/body_size.js#L95)。
- 物種生理說明與混血加權參考都會帶上體型；體型與契合只供敘述參考，不限制交合與受孕。
- **體態**：告訴模型這個種族怎麼出場、孕肚長在哪，也預留給日後的三圍與孕肚變化。分四種：**人形**（胸、腰、臀三圍都適用，孕肚是前腹隆起，眼魔、蝙蝠娘形態的拜亞基、寄居在寶箱裡的寶箱怪、傘蓋與觸手如裙擺的水母族也算）、**半人形**（人類上身接非人下半身，胸圍適用。獸身的半人馬、阿拉克涅、百足氏、蠍羅氏，子宮與孕肚在下半身的獸軀；尾身的人魚、蛇人、梅杜莎、海妖、海馬族、海蛞蝓族沒有腿，孕肚在前腹。都可借魔法化出人腿，變化態縮成人身大小：半人馬、阿拉克涅、百足氏、蛇人、梅杜莎、海妖 5→4，蠍羅氏 4→3，海蛞蝓族 3→2；人魚、海馬族化人前後都是 4，不另設變化態）、**非人形**（三圍不適用：怪獸類、怪鳥類、怪魚類）、**任意**（形體不固定，能變化形體或同族形態差異大：修格斯、史萊姆、觸手怪、燭靈、植物族、真菌族、心魘等）。能變形的種族記人態，例如奇美拉人態為人形、真身是約獅子大小的合成獸。混血按血統，佔比最高的體態勝出，任意不參與，平手取較接近人類的。物種生理說明與混血參考各帶一行體態與描寫方式；註冊時的種族名錄在每族的辨識提示後附「級數·體態」，例如「半人馬(…·5級·半人形)」，有變化態寫成「4→7級」。[體態](../../scripts/race_config.js#L48)。

### 世界基準與提示詞名錄

- **世界基準**：描述整個劇本共通的人類生理、性別角色與社會常識，會送入主線、追蹤、註冊與繁育推演；留空就採用普通人類與現實社會常識。世界基準不屬於物種名錄。[世界基準](../../scripts/race_prompt_context.js#L22)。
- **寫實世界**：開啟後只有人類，不送物種名錄、衍生類型名錄、種族生理、伴生卵定義、胚型說明，追蹤提示也拿掉衍生類型、血統份額、伴生卵與 flux 的欄位說明（全人類故事的追蹤系統提示約少 19%）；名錄勾選變灰，註冊提示要求種族一律填人類；族譜肖像改用人生階段圖示（見[畫面呈現](presentation-and-source-map.md)）。除此之外只減少提示詞，不改任何計算。可存全域或綁在角色卡上，取代了舊版的「現代寫實」按鈕。[世界模式](../../scripts/world_mode.js)。
- **特殊妊娠工具**：代孕／注卵（`bsImplantEmbryo`）、胎歸（`bsWombReturn`）、延產（`bsExtendPregnancy`）各有開關，預設全開；關掉的工具不提供給追蹤模型，它產生的狀態說明也一併不送。開關與寫實世界互相獨立，例如寫實世界也能單獨保留秘傳胎歸。可存全域或綁卡，卡片只記改過的那一項。
- **生殖遊戲參數**：展開後只調整套子容量、套子可靠度與即时事後避孕成功率，按「保存生殖基準」保存。事後避孕窗口自動沿用角色的著床時長，其餘察覺與經驗參數不在介面要求填寫。預設值與規則見[生殖認知與避孕](reproductive-tracking.md#自然線索與遊戲基準)。
- **提示詞名錄**：勾選這個故事可能登場的物種與衍生類型，只有勾選的會送進追蹤與註冊的提示詞，勾選即保存。物種依目前生效的胚型分組，人類列在胎生組，和其他物種一樣可勾選。人類的生理說明只在勾選人類時才送：奇幻設定用它與其他物種比較；取消勾選時由模型常識與世界基準處理人類，其他物種的生理說明不受名錄影響。「全部收錄」勾選全部。1.1.3 以前保存的名錄沒有人類：有勾選任何項目的自動補上人類，全部清空的維持不送。[名錄](../../scripts/race_prompt_context.js#L64)。

## 計算器

計算器是**唯讀推演**：不擲骰、不寫入任何角色，使用目前的百科參數覆寫。

- **自然受精**：給卵方種族、判定時間與多組精源，算出受精機率與各精源的佔比；同條件的精源與排列順序無關。只在卵方至少有 1 顆可用卵、且當下階段允許自然受精時才判定。[受精預覽](../../scripts/calculator.js#L58)。
- **後代預測**：給雙方種族、精液量與受精階段，顯示核型規則、後代種族、胚型來源；有伴生卵的種族另外顯示伴生卵範圍。[後代預覽](../../scripts/calculator.js#L174)。
- **衍生遺傳**：推演胎兒在孕期中衍生類型遺傳軸的每日變化。[衍生遺傳](../../scripts/calculator.js#L322)。
