# 特殊流程與資料不變條件

[返回機制索引](README.md)

## 胚胎 tag 如何產生

系統認得九種 tag。`deriveFetusTags` 會把**可由欄位即時計算**的標記與 `fetus.tags` 中**事件發生時寫入**的標記合併、去重，按固定順序顯示；未知 ID 會被丟棄。tag ID 存英文，中文是介面標籤。[目錄與推導](../../scripts/fetus_tags.js#L19)。

| tag | 產生時機與條件 | 儲存方式 |
| --- | --- | --- |
| `chimera`（嵌合體） | 著床前至少兩顆胚胎可配對，受精進度超過 1 日後，每對按種族同卵率、受孕難度、胚型及衍生類型計算融合率；成功時合成一胎並寫入 `chimera` 來源資料。同批次的已檢查配對不重擲。[融合機率](../../scripts/tools.js#L1546)、[融合流程](../../scripts/tools.js#L1629) | 從 `chimera` 欄位推導。 |
| `surrogacy`（代孕） | 遺傳母方 `providerSources`／`provider` 與承載者不同時成立；`bsImplantEmbryo` 可指定供體。[母源判定](../../scripts/fetus_tags.js#L101)、[植入工具](../../scripts/tools.js#L5400) | 從母源與承載者名稱推導。 |
| `selfing`（自交） | `fathers` 中至少一個有效名字與遺傳母方名字相同。[親代比對](../../scripts/fetus_tags.js#L110) | 從親代欄位推導。 |
| `identical`（同卵） | 著床成功時按胎兒種族的 `identicalProbability` 抽分裂，可成 2–4 胎；原胎與新胎共享 `identicalGroup`。異期胚胎著床只對新批次抽籤。[分裂流程](../../scripts/tools.js#L1710) | 事件寫入各胎 `tags`，另存 `identicalGroup`。 |
| `rebirth`（胎內回歸） | `bsWombReturn` 把回歸者建成胎兒時寫入。[工具實作](../../scripts/tools.js#L924) | 寫入 `tags`。 |
| `superfetation`（異期復孕） | 孕早期在受精窗口內已有卵、精源並再次受精，或在窗口內追加代孕胚胎時寫入。自然受精的機率係數為 `0.10 × (1 − 當前有效孕日 / 窗口上限)`；窗口上限是 `max(0, 孕早期 98 − 著床所需實際日數 × 有效孕速)`。[自然窗口](../../scripts/tools.js#L1292)、[受精路徑](../../scripts/tools.js#L2584)、[植入路徑](../../scripts/tools.js#L5400) | 寫入 `tags`、`conceivedAtDays`，並在著床前標為待著床。 |
| `nested`（孕中孕） | 自然異期受精成功後，若當前有效孕日達 56、精源總量大於 100，且已有胎重至少 1.5 的已著床宿主胎，則新胎寄在宿主體內；優先選最重者，同重時優先女胎，性別不設限。宿主胚型只限胎生、胎轉卵生（受精視窗在孕早期，殼還沒合攏）與不定型；卵生在殼裡、卵胎生在卵膜裡，精液進不去，這時只是普通異期胎。宿主是胎轉卵生時，殼合攏後內胎被一起封住：它的胎膜不扣耐久、破膜工具會拒絕，只會隨宿主一起娩出。註冊與調試注入也套用同樣的宿主限制。[宿主條件](../../scripts/tools.js#L1233)、[受精判定](../../scripts/tools.js#L2430) | 同時寫入 `nested` 與 `superfetation`，用 `nestedInEmbryoId` 指向宿主。 |
| `androgenesis`（雄核發生） | 精卵雙方恰有一方採特殊核型，且該方的繼承模式為父系時，建立胚胎就標記。[核型判定](../../scripts/race_config.js#L1509)、[建胎](../../scripts/tools.js#L1792) | 寫入 `tags`。 |
| `gynogenesis`（雌核發生） | 同一核型判定中，唯一的特殊核型一方採母系繼承模式時寫入；兩方都是一般或都是特殊核型時不產生這兩種標記。[核型判定](../../scripts/race_config.js#L1509) | 寫入 `tags`。 |

`superfetation` 的新胚胎需要經過自己的著床判定；未著床就進入孕中期會被移除。成功著床的普通異期胎在有效孕日 98（孕中期開始、14 週）揭曉，`nested` 在 196（孕晚期開始、28 週）揭曉；揭曉前不進追蹤頁與模型可見胎兒列表，但仍在狀態中發育。[著床與揭曉](../../scripts/tools.js#L2483)。

開局已懷孕時，註冊模型可直接給特殊來源欄位與 `tags`，使用者也可在註冊頁指定來源。正規化會把 `nestedInIndex` 換成宿主 `embryoId`、撤銷沒有有效宿主的 `nested` 與孤立的 `identical`，並依 `conceivedAtDays` 對齊異期標記；代孕、自交與嵌合仍由支撐欄位推導。[註冊規則](../../scripts/registry.js#L992)、[標記校正](../../scripts/registry.js#L1436)。調試工具也能直接注入指定來源或強制同卵／嵌合，見[工具參考](tool-reference.md#ui-診斷工具)。

## 外源胚胎植入

`bsImplantEmbryo` 用於代孕或胚胎移植等情節：`provider` 記錄母源歸屬，`race`／`fatherRace` 決定遺傳資料，承載者只負責妊娠。工具把胚胎加入共用的受精／著床窗口，並非一呼叫就成為已著床胎兒。產後若只有單一母源，可將子女紀錄轉交供體；多母源嵌合體留在孕母名下。[植入工具](../../scripts/tools.js#L5400)、[子女轉交](../../scripts/tools.js#L3801)。回歸期中禁止再植入。異期復孕只在允許的早期窗口生效。[孕期窗口](../../scripts/tools.js#L1292)。

## 胎內回歸

`bsWombReturn` 讓另一人回到承載者子宮；回歸者可未註冊，但承載者必須已註冊，不能自己回歸自己。承載者只可處於月經四階段或無經期，也不能本身已在別人體內。操作先清空承載者原有精源、卵及胎兒，再建立一個帶 `rebirth` 標記的胎兒。回歸者的種族來源按「明示參數 → 已註冊回歸者 → 承載者」決定；胎兒繼承天賦，技能不直接帶入。[工具實作](../../scripts/tools.js#L924)。

回歸期以 `hours` 倒數，胎重從 3.0 線性降到 1.0；到期轉入孕早期第 1 日，超出的時間一併算入孕日。`hours=0` 立即完成。若回歸者已註冊，其 `wombReturnHost` 會讓時間推進凍結，部分生理工具也被擋下；承載者被註銷後，下次時間推進會解除這種凍結。[時間與凍結](../../scripts/tools.js#L848)、[受阻工具清單](../../scripts/tools.js#L834)、[全員時間推進](../../scripts/tools.js#L6483)。

若在回歸期使用 `bsAbortion` 中斷，規則視為回歸者被消化吸收，已註冊的回歸者保持凍結；這條路徑不會把她還原成普通角色。[中斷分支](../../scripts/tools.js#L5308)。

## 指定胎兒與隱藏胎兒

胎兒陣列包含尚未揭曉的異期胚胎、巢狀胎兒等。對模型開放的 `fetusIndex` 按**可見胎兒列表**定位；例如定向流產會先將可見序號解析為胎兒，再刪除實際陣列中的對象，避免誤刪未知胚胎。同一批工具呼叫裡，序號一律以模型收到資料時（這批開始前）的可見順序為準：前面的工具推進時間讓胎兒換位，或已經減掉一胎，後面的序號仍指向原本那一胎；那一胎已不在時視為無效序號而拒絕。巢狀胎兒所依附的承載胎兒被移除時，也會一起移除。[可見胎兒解析](../../scripts/tools.js#L4383)、[指定流產](../../scripts/tools.js#L5221)。

同卵組、胚胎 ID、羊膜分組與先露 ID 是不同的識別用途。每次工具執行前，胚胎編號計數器會先越過現有最大號，以免刪胎後重發舊號；執行後再修正破膜巢狀胎、先露參照和下降位置。[工具前後整理](../../scripts/tools.js#L7860)。

## 直接流產與自然危機

`bsAbortion` 可指定可見胎兒，也可清除整個受孕／妊娠狀態。`immune.miscarriage` 會擋工具，除非明示 `force`。沒有胎兒的假孕不能用它結束，應走月經階段設定。著床前終止回到卵泡期；已進入孕期且清空胎兒後，通常轉產後恢復並增加流產經歷。[工具實作](../../scripts/tools.js#L5221)。這與宮壓觸發的自然流產是兩條程式路徑；後者先警告，再於下一次仍高壓的推進判定。[宮壓危機](../../scripts/tools.js#L4695)。
