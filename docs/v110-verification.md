## 真實宿主仍待驗收

離線与 mock 不能證明真實 SillyTavern、TauriTavern、Luker 的完整行為，也不能證明實際模型一定採用「下一輪承接」文案。需要在實際聊天確認：

1. 載入旧聊天与 swipe／刪樓後遷移只執行一次、角色與來源結果恢復一致。
2. 多人在場与離場切換、假孕／恢復結束、實際月經入口及預植紀錄的保留／刷新。
3. 真實推演 API 失败、重试与转側，以及請求中切聊天／swipe 的結果棄置。
4. 戴套／事後藥成功和失敗由下一次敘事承接，角色不無故知情或揭露未知胎父、胎數。

本次没有安装、部署或发布；程式可供下一步實機驗收。
