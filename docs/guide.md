# BS BioTracker 使用說明

BS BioTracker 會依角色設定與對話追蹤角色狀態。插件內的 PDA 右上角有 `?`，可隨時打開精簡版說明；這份文件則依使用順序整理操作步驟。想了解判定條件、計算方式與工具限制，從[機制說明](mechanics/README.md)開始。

## 開始之前

- 安裝 BS BioTracker 並重新載入宿主。SillyTavern、TauriTavern 與 Luker 均在支援範圍內。
- 準備可用的 API Base URL、API Key 與模型名稱。模型需要能穩定輸出結構化結果。
- 每個聊天的追蹤資料分開保存。從 0.x 升級到 v1.0.0 時，舊存檔不再轉換，請開新聊天。

## 1. 設定 API

按 PDA 下方的齒輪鍵進入 `SYSTEM`。

1. 填寫 `OpenAI 兼容 API Base URL` 與 `API Key`。
2. 在 `API 格式` 選擇服務使用的端點格式。一般 OpenAI 相容服務使用 `/chat/completions`；介面也提供其他自訂格式。
3. 按 `连接并拉取模型` 選擇模型。若服務不支援模型列表，直接在 `模型名称` 輸入名稱即可。
4. 勾選 `启用异步生理状态追踪`，按 `保存设置`。

`触发时机` 可選 AI 回覆後的 `after_ai` 或使用者送出訊息後的 `after_user`。第一次使用可先維持預設值；需要調整送入分析的訊息數時，再修改 `送入分析的最近消息数`。

## 2. 註冊角色

回首頁進入 `注册`，填入角色名與種族。種族旁的 `☥` 可打開選擇介面。

- `推演`：可先讓 AI 建立角色專屬的繁育心理設定；這一步可跳過。
- `注册`：可填補充設定與描述規則，確認後建立角色初始狀態。
- `着衣`、`日记`、`技能`：按需要設定起始服裝、寫第一篇日記、配置初始技能／天賦。三頁各自能生成、微調預覽後再寫入；`一次注册` 則在同一個請求裡把三者跟註冊一起做完。

系統頁的 `着衣系统`、`技能系统` 開關可整個關掉對應功能：入口與子頁隱藏，追蹤模型也看不到相關工具與狀態，已有資料會保留。

註冊補充設定下的「初始認知紀錄」可預植故事日期、方式與內容，允許猜測或錯誤，與日記分開保存。

直接註冊不會自動產生繁育心理人設。若要用推演結果作為角色設定，請先完成推演，再註冊。

註冊時 AI 會依角色資料判定 1–7 級的**活力等級**與**情壓等級**；它們表示長期體質與情緒特質，不是此刻的疲勞或心情。預設都是 4 級，系統據此設定初始活力 125、情壓 55。重新註冊會重算這兩個當前值。

活力／情壓等級、起始數值、開局妊娠及重新註冊的規則，見[角色註冊與初始值](mechanics/registration.md)；每聊天資料如何保存，見[追蹤、API 與存檔](mechanics/tracking-and-state.md)。

## 3. 追蹤對話

進入 `追踪`，按 `立即分析当前对话` 測試一次。插件會分析近期對話並更新已註冊角色的狀態；之後則依 `SYSTEM` 中的觸發時機異步執行。`最新工具调用` 可協助確認最近一次分析的結果。

點選角色後，可以從以下分頁查看資料：

| 分頁 | 用途 |
| --- | --- |
| `概览` | 快速查看目前狀態。 |
| `描述` | 查看角色的狀態描述。 |
| `妊娠` | 查看妊娠與胎兒資料；適用時會顯示像素子宮圖。 |
| `经历` | 查看技能、天賦、經歷與孩子紀錄。 |
| `心情` | 查看心理、當期認知紀錄與日記。 |

`优先追踪角色名` 可選填；留空時，追蹤器會平等檢查所有已註冊角色。

想核對某次模型呼叫為何生效或被跳過，見[全部工具參考](mechanics/tool-reference.md)。

## 4. 推進時間與查看完整資料

進入 `变量`，在 `全角色时间推进` 輸入年、月、週、天、時、分，再執行推進。這會同時作用於目前聊天中的已註冊角色，請先核對時間跨度。

同一入口也可以查看單一角色的 `变量内容`、`历史` 與 `调试工具`。調試操作會直接改變狀態，適合校正資料或測試設定。

時間推進如何影響週期、受孕和產程，見[時間、週期與受孕](mechanics/cycles-and-conception.md)及[妊娠、供養與分娩](mechanics/pregnancy-and-labor.md)。

## 其他頁面

| 首頁入口 | 用途 |
| --- | --- |
| `预设` | 管理追蹤器使用的預設。 |
| `排除` | 選擇世界書的傳輸模式與條目。 |
| `技能` | 管理目前聊天的技能圖鑑。 |
| `衣柜` | 先選角色，再查看衣物與穿著；各分類標題後的 `+` 可新增衣物，臨時衣物可收進衣櫃；`备装` 讓模型代入角色補衣物、汰換穿不下的衣物。 |
| `百科` | 查閱種族、衍生類型與計算工具；`基准` 分頁可寫世界基準，並按胚胎型態分組勾選本故事會出現的種族與衍生類型。 |
| `主题` | 調整 PDA 的外觀與配置。 |

衣櫃四維數值、換裝、技能升級與天賦轉移，見[服裝與技能機制](mechanics/wardrobe-and-skills.md)。

## 遇到問題時

- **拉不到模型列表**：檢查 Base URL 與 API 格式；服務若沒有 `/models`，可手動填寫模型名稱。
- **註冊或追蹤失敗**：確認 API Key、模型名稱與端點可用，並檢查模型是否能穩定輸出結構化結果；接著查看 `追踪` 頁的 `最新工具调用`。
- **狀態沒有更新**：確認已註冊角色、已啟用異步追蹤，並檢查觸發時機；也可先按 `立即分析当前对话` 手動測試。
- **從 0.x 升級後找不到舊狀態**：v1.0.0 不再讀取或轉換舊存檔，請開新聊天。詳細變更見 [Changelog](../Changelog.md)。
