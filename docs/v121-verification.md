## 付費實機

插件 API 是 DeepSeek `deepseek-flash`。正文由我直接寫入（`/sendas`），自動追蹤開著。測試前把全域百科覆寫與名錄勾選還原成原值（空與全部啟用）。

- **註冊選到新物種**：只給外觀描述、不寫種族名。「住在花田、腰部以下埋在巨大粉色花冠裡、根鬚扎進土中、花蕊飄出花粉」→ **爱那温**，體型 3.5，生理值照爱那温帶入（孕速 2、承載 1.5、伴生卵 2）；「兩對手臂、蜜色皮膚、琥珀小翅、小腹圓鼓、翅膀滲蜜露」→ **炉蚜**，體型 3.2（承載 0.5、恢復係數 3.8），描述寫了四臂與蜜露。
- **追蹤寫新物種**：正文寫巨魔格罗姆與花铃交合、一隻和人一樣高的完整蟑螂與阿蜜交配。追蹤記成 `巨魔` 與 `怪虫类`，蟑螂主動帶 `maleBodySize: 4`（怪虫类是依個體）；契合結算花铃 3.5 對巨魔 5「明显不合」0.4、阿蜜 3.2 對 4「略有落差」0.7。
- **模型自己用 `hostFetusIndex`**：正文寫蜜蜜用產卵管把自己與莱昂的受精卵嵌進腹中代孕胎兒。追蹤呼叫 `bsImplantEmbryo`，新胚胎是炉蚜、父方莱昂、寄在第 1 胎體內、等待著床。前一顆孕中孕還沒揭曉，模型看到的可見清單只有宿主一胎，序號 0 對得上。

## 發現與修正

- **核型免疫按鈕不亮**：追蹤頁的檢視模型只帶代謝、流產、真實產程三個免疫欄位，漏了核型，狀態寫入了按鈕卻一直顯示 OFF。已補上。
- **未修（設計如此）**：角色 `bio.inheritanceMode` 一律記 normal，因為合併生理值時核型不參與；實際的受孕判定讀種族，不讀這個欄位，沒有地方用到它。
