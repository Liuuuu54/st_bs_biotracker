# 血統比例

v1.1.2 起，每個角色、精液、胎兒與子女都記錄各種族的血統份額，生理參數按份額加權計算。

## 輸入與顯示

註冊頁點種族輸入框旁的調色盤，上方選擇種族與子項並加入，下方集中顯示已選種族和比例，確認按鈕在列表之後。可用滑桿或數字設定百分比：例如加入精靈與人類，把精靈調到 25%，人類自動補為 75%；三種以上時，其餘種族依原比例分配剩餘份額。「平均分配」可重設為均分。只有一個種族時固定 100%，新增種族後才可調整。

重新開啟註冊或計算器的調色盤會載入欄位現有的比例與衍生子項；確認才寫回輸入框，取消則保留原值。新增種族會分到一份比例，並按比例縮小原有份額；移除種族會把剩下的成分重新歸一為 100%。0% 的成分在確認時省略，重複的種族不會重複加入。衍生型另外設定，不占血統份額；只選了衍生型、還沒加入種族時，寫入的是 `[衍生型]`。

註冊種族輸入框可以填寫：

- `1/4精灵x3/4人类`
- `精灵25%x人类75%`
- `[血族]精灵25%x人类75%`

種族名保存在 `race`，比例另存為 `bloodline`，例如 `{"精灵": 0.25, "人类": 0.75}`；`bloodlineSource` 區分明確指定（`explicit`）、遺傳計算（`inherited`）、舊資料推定（`estimated`）與純種（`pure`）。比例只在顯示時四捨五入，遺傳時不會截掉較小的份額。

只寫 `1/4精灵` 時，剩下的 75% 記為「未知」，不會自動當成人類。包含未收錄成分的生理值仍標示為不完整參考。

角色追蹤頁、胎兒詳情與族譜的節點和詳情都會顯示血統百分比；計算器的預覽與送給模型的種族生理提示也用同一份比例。同一種族與比例在提示中只出現一次，並列出所有擁有者。

## 遺傳與生理

一般遺傳由卵源與精源各占一半，相同成分相加：半精靈 × 人類得到精靈 25%、人類 75%；再與人類回交則是精靈 12.5%、人類 87.5%。原有的九格核型規則保留：只有一方具特殊核型時，依雄核／雌核只取那一方的血統；雙方都具特殊核型時仍各半混合。

一般生理數值按份額做算術加權。妊娠速度先換算成天數，加權後再換回速度：精靈 25%、人類 75% 對應 350 天，而不是直接平均速度。伴生卵沿用「整群＝伴生卵＋1」的尺度，按份額做加權幾何平均。孕期最長的成分決定胚型；份額為 0 的成分不參與。

性別比按份額加權。雙性成分合計占 25% 以上時，後代固定為雙性；低於 25% 時，按其餘成分的性別比計算。無性只在沒有任何一般性別比的成分時成立。

代孕使用實際的卵源，承載者不占血統份額。精源的份額隨殘留精液與接觸紀錄保存；胎兒的份額在出生、轉交與註冊為角色時保留。孕中孕以宿主胎兒為遺傳母親。同卵分裂複製比例；嵌合按參與的受精卵數量加權，結果與融合順序無關。

## 舊存檔

聊天存檔結構升為版本 5。舊的角色、精液、胎兒、子女與樓層快照在讀取時補上比例：純種為 100%；舊的混血字串依基種族均分（同一基種族的裝飾子項共用份額），並標示「比例推定」。系統不宣稱還原了過去世代的真實比例，遷移時也不覆蓋既有的自訂生理數值或進行中的妊娠快照；已經有明確比例的資料保持不變。

舊故事若要恢復真實份額，可在角色註冊資料填入已知比例；未知的祖先比例不會自動補造。

遷移是單向的：聊天在 1.1.2 開啟過一次後，退回 1.1.1 或更舊的版本便無法正確讀取。升級前請先備份 SillyTavern 的 `data/<使用者>/settings.json`。
