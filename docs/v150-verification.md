## 驗證中的修正

1. **全裸時特寫仍畫胸衣與短褲**（1.4.3 起）：`mainItemId=0` 對到衣櫃保留的「全裸」，特寫只認「沒有主衣物」或穿著狀態寫明全裸，所以畫成有穿、放鬆胸型也看不到。改成 id 0 也算全裸。
2. **`define` 的回傳出現舊工具名**：登記成功的訊息是「bsRegisterSkillDefinition registered…」，改成「define registered…」，免得模型以為還要另外呼叫。
3. **轉化說明**：補上「要花時間的先 transform（給 hours）再推進時間」與「排斥的傷害由系統結算，不要另用 bsFetalEvent 記」。第二輪重跑確認模型照做。
4. **一次生完多胎的出生順序**：`bsChildbirth` 照胎兒清單順序編「第幾胎」，先露、已在產道的那胎被記成第 2 胎。改成先露的先出，其餘照下降深淺。

## 沒有驗證的

- **產傷**：這次卡住的情境沒出現（橫位那胎沒入盆，先露換成頭位那胎），肩難產、互鎖、橫位卡住的每小時扣量與產傷只有單元測試。
- **原生工具調用成功的那條路**：deepseek-flash 每次都沒交完檢查清單，只驗到退回；換能完整發出工具調用的模型才看得到。
- **孩子以卵方身分註冊**：只驗了精方。

## 發現的問題（待決定）

- **未成年的孩子也能註冊**：剛出生的孩子註冊成精方時，註冊模型照樣填了「性器」等描述，寫的是新生兒。孩子未成年（或該族未成年）時應該擋下註冊，或不要求性器官與性相關欄位。
- **年齡 0 記成未知**：剛出生的孩子註冊後年齡是 null（精方檔案只收大於 0 的年齡）。
