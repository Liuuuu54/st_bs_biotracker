# 各文件功能与摘要汇总

本文件详细记录了 **BS BioTracker** 插件中每个代码文件的具体定位、内部主要逻辑、重要常数/方法，以及它在系统中的协作关系。

---

## 一、 根目录文件说明

### 1. `index.js` (项目入口与 UI 交互控制器)
- **定位**：插件的主入口脚本，由 `manifest.json` 指定在 SillyTavern 启动时加载。
- **核心功能**：
  - **模块导入与挂载**：引入 `scripts/` 下的所有配置和核心引擎逻辑，挂载到全局变量或宿主扩展节点。
  - **UI 页面渲染**：操作 DOM 填充 `settings.html` 中的模板，渲染「概述」、「注册」、「追踪」、「技能图鉴」、「衣柜管理」、「系统设置」等多个子页面。
  - **浮动功能球 (Floating Sphere)**：实现了可以在屏幕上自由拖拽的浮动状态球，支持长按呼出追踪菜单、双击开启即时分析、以及显示更新气泡通知（`UPDATE_CUE_EVENT`）。
  - **宿主生命周期监听**：注册 SillyTavern 等宿主平台的事件回调（如 `APP_READY`、`CHAT_CHANGED`、`CHAT_CREATED` 等），在聊天切换、新对话创建、对话删除时执行相应的状态重置或快照同步。
  - **主题切换逻辑**：支持包括 `retro`、`cultivation`、`fantasy` 等 12 种主题风格的 CSS 类切换。

### 2. `settings.html` (前端 DOM 模版)
- **定位**：插件的 HTML UI 结构文件。
- **核心功能**：
  - 提供了插件的侧边栏、主模态窗口（`MODAL_ID`）以及各个设置子页面的静态 HTML 布局。
  - 包含时间流逝推进输入、注册表单、技能和天赋的调整列表、衣物属性编辑表单等。
  - 包含各种数据绑定的 placeholder 容器，通过 `index.js` 在运行时动态填充数据。

### 3. `style.css` (视觉样式表)
- **定位**：定义了插件的界面样式，包含十二种不同主题的主色调、边框、进度条、浮动球的样式等。
- **核心功能**：
  - 定义了 CSS 变量用于实现 Retro（复古电脑）、Cultivation（修仙）、Eldritch（古神克苏鲁）等十二种风格的换肤机制。
  - 处理了在手机、PC 上的响应式布局适配（配合 `deviceSize` 选项）。

### 4. `manifest.json` (插件元数据)
- **定位**：SillyTavern 插件标准声明文件。
- **核心功能**：
  - 声明插件的显示名称 (`BS BioTracker`)、版本号、作者、依赖的 JS/CSS 入口以及加载优先级（`loading_order: 20`）。

## 二、 `scripts/` 目录核心代码文件 (第 1 部分)

### 1. `api.js` (LLM API 客户端与网络桥接)
- **定位**：处理所有与 OpenAI 兼容接口的 HTTP 交互和结果解析。
- **核心功能**：
  - **结构化输出防护**：支持对不同 LLM 自动适配（例如识别 DeepSeek 系列模型并额外注入结构化 V4 提示词、开启/关闭 `response_format`）。
  - **JSON 提取容错**：`extractJson()` 方法支持从 Markdown 代码块（` ```json `）、脏文本、甚至未闭合的大括号截取中安全还原出 JSON 对象，防止因为模型输出多余解释文字而报错。
  - **代理请求**：由于部分环境的跨域限制，提供了 `buildHostProxyConfig()` 函数，优先利用宿主环境的代理转发 API 请求并带上 CSRF Token。

### 2. `host.js` (宿主兼容层驱动)
- **定位**：抹平不同宿主软件（SillyTavern、Luker、TauriTavern）之间的 API 差异。
- **核心功能**：
  - **宿主类型侦测**：自动检测环境是 SillyTavern Web版、TauriTavern 桌面版还是 Luker 核心。
  - **聊天视图分片读取**：支持异步拉取极长历史记录（针对桌面版 TauriTavern 的分卷读取）。
  - **世界书 (World Book) 与预设加载**：提供从宿主获取当前绑定世界书、人设卡、场景设定、当前 API 预设的底层接口。
  - **事件订阅发布代理**：通过 `subscribeHostEvent` 挂载宿主的事件钩子，确保宿主变更时插件能正常获取最新消息。

### 3. `state.js` (全局状态及持久化数据管理器)
- **定位**：插件核心的数据库和状态机，控制所有内存和本地存档读写。
- **核心功能**：
  - **快照及差异修补 (Snapshot & Patch)**：实现了一个多级撤销/回退机制，保存最近 24 次的对话状态快照。使用 JSON 增量补丁（支持删除哨兵和数组追加）大幅压缩存储占用，防止 SillyTavern 存档因为数据量过大导致崩溃。
  - **数据规范化 (Normalization)**：提供初始化新角色状态（`createDefaultFemaleState`）、心智状态序列化、以及将存量非标准字段转换为标准的健壮性校验函数。
  - **生理速度计算**：提供计算特定角色的妊娠推进速度（结合环境乘数、种族特异速度以及母体体质倍率等）。

### 4. `tracker.js` (追踪异步循环调度引擎)
- **定位**：负责异步监听聊天动态，并触发 AI 追踪器进行分析。
- **核心功能**：
  - **轮询控制**：在 `after_ai` 或 `after_user` 时机，延迟一段时间后轮询检查最后一楼消息是否已发生变化。
  - **变量更新门控 (MVU Gate)**：协调与 ST 另一个著名变量插件 MVU 的运行锁冲突。检测到 MVU 正在执行额外模型解析更新时自动等待其完成，防止并发请求产生竞争且浪费模型额度。
  - **主工作流拼装**：从 `state`、`host` 中组装当前的 `existing_state`、历史消息以及可用工具清单，将整体 Payload 传递给 `api.js`，得到工具调用指令后交由 `tools.js` 执行。

### 5. `tools.js` (工具指令定义与执行引擎)
- **定位**：定义了 LLM 可以调用的全部底层工具（函数）以及它们在状态树上的具体演算规则。
- **核心功能**：
  - **工具 Schema 定义**：`TOOL_DEFINITIONS` 数组中包含了所有向 AI 声明的 JSON Schema，如 `bsPassedTime`、`bsUpdateCharacterStatus`、`bsUpdatePsychology`、`bsChangeOutfit` 等。
  - **业务逻辑演算**：
    - `bsPassedTime`：执行非常复杂的生理演化推进（例如从黄体期到月经期，受精卵着床几率推算，多胎胎儿发育，产程小时累积，宫压对破水的影响等）。
    - `bsChangeOutfit`：改变角色当前穿着的主件、配件状态，并叠加衣物的遮掩（masking）、支撑（support）、容身（capacity）、便捷（convenience）等四维数值。
    - `bsTrainSkill`：对后天技能增加 EXP 并处理自动升级。
    - 其它辅助工具：精液管理（`bsAddSperm`/`bsDrainSperm`）、写主观日记（`bsWriteDiary`）、流产（`bsAbortion`）等。

### 6. `registry.js` (角色初始设定推演器)
- **定位**：新角色注册时的 LLM 自动化配置工具。
- **核心功能**：
  - **推演接口**：用户提供名字和种族补充后，调用 LLM 对角色卡、世界书、初始对话进行通读。
  - **属性预生成**：推演其繁殖特征（胎生/卵生等）、生成符合其性格的生理状态初始描述、准备衣柜的初始配装、建立首篇登场前夜的主观日记、并分配合适的初始技能与天赋。

### 7. `race_config.js` (生殖特征与种族常数数据)
- **定位**：项目的生物学底层数据库。
- **核心功能**：
  - **生殖类型划归**：定义五大体系所包含的种族（例如胎生包含人类/精灵/兽人；卵生包含鸟人/蜥蜴人等；胎转卵生包含龙族/恶魔等）。
  - **生理配置表**：定义各种族在未定义时的基础代谢率、恢复时间、产仔数量、妊娠难易度和生殖隔离参数。

### 8. `stage_config.js` (生命阶段时间切片定义)
- **定位**：时间流逝的周期和时限常量。
- **核心功能**：
  - 定义月经阶段天数（如卵泡期 9天、排卵期 2天等）。
  - 定义妊娠阶段天数（如孕早期 84天、孕中期 105天等）。
  - 定义分娩三产程的基础消耗小时数（如第一产程 12小时、第二产程 2小时）和多次生育后的产程缩减公式常量。

### 9. `wardrobe_config.js` (衣柜系统规格化校验)
- **定位**：衣柜数据模型和穿衣行为过滤器。
- **核心功能**：
  - 规范衣服的槽位类型（主件 main，配件 accessory）。
  - 规范四维属性（掩形、支撑、容身、便捷），限制配件的得分不能超过 ±3 且最多影响两个维度。
  - 维护临时装（`temporaryItems`）和长期装的管理，过滤不合规的 ID 或空的装备名称。

### 10. `skill_config.js` (技能与天赋机制配置)
- **定位**：技能系统的规则、经验曲线与数据清洗。
- **核心功能**：
  - 经验公式：`requiredExp = 100 * level * level`。
  - 技能与天赋图鉴：实现新增定义、删除定义、经验添加等数据清洗。
  - 自动升级机制：计算技能在锻炼后是否突破当前等级上限，记录到最近 100 条升级日志。

### 11. `memory_sources.js` (外部记忆桥接器)
- **定位**：长文本或外部插件记忆提取模块。
- **核心功能**：
  - 实现从 SillyTavern 官方的 Anima 扩展、第三方柏宝书（STBaiBaiBook）或世界书里的特定命名条目中，采用中日韩二元滑动窗口分词（Tokenizer）和相关性打分算法，为 Tracker LLM 提供当前故事的背景记忆快照。

### 12. `registry_psy_config.js` (心智状态分级标准数据)
- **定位**：描述角色心理变化的量化标准。
- **核心功能**：
  - **三大指标六大阶段**：针对感知度、渴望度、自主性等，详细列出了从 0、1~25 到 100+ 等各个数值区间的行为表现。
  - **升级/越限条件**：详细规定了如从 0 突破到 1+ 必须经历的事件，以及超越 100 时触发的特定心理转变表现。

### 13. `tracker_prompt_context.js` (Tracker 提示词构造器)
- **定位**：整合所有运行时信息用于构造发送给 Tracker 的 System Prompt。
- **核心功能**：
  - 把 `state` 中的各个字段语义、`tools.js` 中所有工具的作用、各种族的详细生理限制等转化为高密度的 prompt 上下文，确保 AI 能做出极其精准的工具调用选择。

### 14. `race_prompt_context.js` (种族名录提示词构造器)
- **定位**：将复杂的种族配置输出为对 AI 友好的中文名录提示词。
- **核心功能**：
  - 拼装可用种族名录、衍生类型，给出各种混血写法指导，并在注册和追踪阶段分别使用简版或带辨识提示的详版。

### 15. `embryo_prompt_context.js` (生殖体系补充 Lore 提示词构造器)
- **定位**：自动提取关联的胚胎类型 Lore 附带到 System Prompt 之后。
- **核心功能**：
  - 解析当前角色和精液里的种族，有针对性地送入相应体系（例如“胎生”与“胎转卵生”的混合描述），防止 LLM 忽略小众妊娠阶段的物种特点。

### 16. `registry_config.js` (注册引导常量)
- **定位**：注册向导所使用的基础 Prompt 模板。

## 三、 `tests/` 测试文件目录说明

测试目录下包含了该项目大量的单元测试，测试主要使用 `mjs` (ES Modules) 规范，能够帮助开发者快速校验自己的逻辑修改。

- `api.test.mjs`：API 请求与 JSON 抓取模块的单元测试。
- `host.test.mjs` / `host_proxy_csrf.test.mjs`：宿主环境检测与 CSRF 请求头校验测试。
- `mvu_gate.test.mjs`：Tracker 调度中与 MVU Gate 的状态等待与门控逻辑测试。
- `labor_rupture.test.mjs` / `ovulation.test.mjs`：生理演进中如排卵、分娩、产力计算逻辑的单元测试。
- `race_catalog.test.mjs` / `race_hybrid.test.mjs`：种族配置、混血解析（如 `x` 分隔符及 `[derived]` 处理）测试。
- `registry_fixes.test.mjs` / `audit_fixes.test.mjs`：注册和审计数据清理的纠偏逻辑测试。
- `wardrobe.test.mjs`：衣柜四维得分、Slot 合规性与临时装过滤的单元测试。
- `tracker_pipeline.test.mjs` / `tracker_reconcile.test.mjs` / `tracker_run_lock.test.mjs`：异步 Tracker 主流水线、快照同步以及死锁防止（看门狗）测试。
- `ui_contract.test.mjs` / `ui_server.mjs` / `ui-harness.html`：前端 UI 行为和通信协议测试，包含模拟服务器。
