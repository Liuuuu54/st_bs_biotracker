## 付費實機（2026-10-08）

### 測試環境

- **宿主與插件**：使用者安裝的 SillyTavern 1.19.0，第一、二輪插件在 b3b9b1f，受孕流程在 6726b69。
- **模型**：主連線與插件推演都用 DeepSeek `deepseek-flash`。
- **主模型預設**：使用者自己的「夏瑾 天琴座 V2 Beta 1.0」，推理強度維持 max，每輪約 66–90 秒。
- **進行方式**：測試前備份 `settings.json`。測試卡用 API 匯入，追蹤模型在主模型回覆後自動執行。

### 第一輪

| 項目 | 結果 |
|---|---|
| 從介面把寫實世界存到角色卡 | 通過：存成 `{realisticWorld:true, version:1}`，生效值為開，全域仍是關 |
| 卡上設定格式不合 | 測試卡最初少了 `version`，插件提示「格式不受支持」並拒絕覆寫原資料；這是保護機制，行為正確 |
| 寫實世界的註冊提示 | 開頭有「只有人類」指令；`<bs_race>`、種族名錄、胚型、咒縛都沒送；角色註冊為人類 |
| 寫實世界的追蹤提示 | 不送名錄；資料標記寫實世界 |
| 排卵與受精 | 排卵期滿一天後自然排卵 1 顆。兩次內射都由追蹤模型以 `bsAddSperm` 記錄，精液殘留正確累計，卵在每次推進時間時都有受精判定；這兩輪沒有受孕，在機率範圍內 |
| 高潮排卵路徑（直接呼叫工具） | 性慾推到上限時多排 1 顆，排完性慾歸零 |

| 真實面板 | 極需居中占兩排，在使用者的 iPhone 主題下正常 |

第一輪發現的問題與修正（5ac04ef、e38db09）：

- **高潮排卵從未觸發**：劇情兩次寫角色高潮，追蹤模型都只調低性慾，因為提示從沒說高潮該怎麼表示。1.1.4 的異卵雙胎幾乎都來自高潮排卵，不修的話實際遊玩時雙胎率會接近 0。修正：`bsUpdateCharacterStatus` 新增 `orgasm` 選項，追蹤提示也寫明用法。
- **寫實註冊提示仍送非人類欄位說明**：包括血脈比例、flux、`[血族]人类` 範例、伴生卵、精靈懷孕範例。修正：寫實世界下整行拿掉。
- **年齡落回 15 歲**：角色卡只寫「外表二十多歲」的血族，模型沒填年齡，就落回預設的 15。修正：註冊提示要求年齡必填。
- **臨時鍵空殼**：切卡時留下空的臨時鍵狀態 `80:solo`；v1.1.3 驗證時就看過這個現象。修正：臨時鍵不落盤，載入時清掉舊空殼。

以下三件事不是插件的問題，記在這裡供日後參考：
- 註冊表單的「自訂備註」欄留著使用者先前填的懷孕設定，第一次註冊因此被登記成臨產。
- 直接改聊天狀態而不記快照的話，下次讀取會被舊快照還原；這是測試手法造成的，插件自己的註銷流程會記快照。
- 直接改狀態時，主模型的注入提示不會跟著更新。

### 受孕流程（6726b69）

為了確定能受孕，把測試角色的受孕難度暫時設成 0.01，受精後改回 1。程式的下限是 0.1，所以實際上是 0.1。這個設定只影響受精這一次擲骰，同卵分裂等其他判定都不受影響。

| 輪次 | 結果 |
|---|---|
| 第一輪（同房、隔天） | 劇情只寫「纏綿到深夜」，追蹤模型自己判斷角色高潮，傳了 `orgasm:true`。自然排卵加高潮排卵共 2 顆卵，都受精，懷上一女一男的異卵雙胞胎；提示「林晓受精成功」；角色認知為空 |
| 第二輪（十天後） | 著床進入孕早期，產科孕日 35。角色出現疲倦、反胃、胸脹，自己去驗孕，結果是一條線加一道淡影；追蹤模型把這記為「驗孕」認知，結論不確定 |

這兩輪發現的問題與修正：

- **主模型在著床前就看到「受精成功」**：主模型的狀態裡帶著這條系統提示和胎兒資料。它因此讓角色在受精第 11 天就出現孕兆、去驗孕，還寫出「經期晚了將近十天」，但這時經期根本還沒到。修正：著床前，主模型看不到胎兒資料與受精提示；追蹤模型不受影響。
- **孕早期出現「第1胎下降到子宮低位」**：胎兒位置原本在整個孕期都會浮動，孕早期的胚胎只有幾毫米也一樣。修正：孕早期不浮動、不翻身、不發位置提示，孕中期起才活動。
- **追蹤模型的認知紀錄與正文矛盾**：正文寫「算一算還沒到」，追蹤模型卻記成「經期晚了將近十天」。這是追蹤模型自己總結錯了，程式這邊沒有防護。

這兩項修正只經過自動回歸，以及 SillyTavern、Luker 的隔離實機重跑，沒有再做付費實機。

### 清理

每一輪結束後都刪除了測試卡、聊天、追蹤狀態和標籤紀錄，並還原使用者的註冊備註和最後選中的角色。比對結果：

- `settings.json` 的頂層設定、插件設定與聊天狀態，都與每輪清理前的備份完全一致。只有一處不同：受孕流程那輪載入 6726b69 時，使用者設定裡一筆沒有角色、沒有快照的臨時鍵空殼 `219:solo` 被清掉，這正是臨時鍵修正的效果。
- 與測試前相比，只多了以下差異，都是正常行為：
  - 插件補上寫實世界與工具開關的預設值；
  - 使用者打開的一個舊聊天從 schema 4 遷移到 7；
  - 送訊息時的 token 計數。

## 未涵蓋

- **後續兩個 commit**：華根蘊桃伴生卵（667cc78）與寫實族譜圖示（94e78fb）只經過自動回歸、mock 與隔離實機，沒有付費實機。圖示是純顯示，不經模型。
- **衍生 flux 的釋放**：這部分沒有實際觸發。劇情裡的血族白天在棺木沉睡、晚上聊天，活力沒有變化，所以血欲停在平衡。這是設計：flux 和一般種族的飢餓、睡眠一樣，靠活力消耗累積，不在孕期時不會隨時間自己上升。平衡狀態下喝一杯血酒，如果去「解放」，反而會把血欲推往負極的醉血，所以追蹤模型不動 flux 是正確的。由正、負極去解放的流程，本版沒有在付費實機觸發過。
