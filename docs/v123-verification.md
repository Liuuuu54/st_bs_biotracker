## 付費實機

插件 API 是 DeepSeek `deepseek-flash`。只給外觀描述、不寫種族名：

- 「腰部以下是帶斑點的灰色海豹身軀與後鰭，上岸時脫下海豹皮變出人腿」→ **赛尔克族**，體型 4（9 秒）。
- 「身材高大的斑點獸人女戰士，圓耳、長吻，部族由女性掌權」→ **鬣狗族**，體型 5（7 秒）。
- 「臉頰有紅色電氣囊、閃電形尾巴的黃色電氣鼠寶可夢少女」→ 自訂的 **宝可梦**（6 秒），生理值照自訂物種帶入；模型沒有自己加上子項「-皮卡丘」。

## 沒驗到

- 新物種的族譜圖示只在預覽工具看過。
- 自訂物種在追蹤一輪裡的表現（例如精方是自訂物種時的體型契合）沒有跑真模型。
- 測試留下的角色（海铃、阿卡、小黄、修修、龙娘）在 Seraphina 測試聊天裡；小黄的種族「宝可梦」在刪除自訂物種後變回名錄外。
