# 种族生理、生命周期与时间流逝逻辑

本文件详细剖析项目中各种族的生理特征、五大生殖系统设定，以及在调用推进时间工具（`bsPassedTime`）时生理状态与产程的底层演化逻辑。

---

## 1. 五大胚胎生殖体系

项目的种族分类逻辑由 `scripts/race_config.js` 管理，各种族均归属于以下五类胚胎类型（`embryoType`）之一：

1. **胎生 (Viviparous)**：
   - 遵循常规哺乳类生理，未受精时子宮內膜脫落出血（月经）。
   - 胚胎依赖胎盘与母体循环交换营养。多胎发育风险较高。
   - 新生儿出生时生理成熟度极低，极度脆弱，需长期哺乳照护。
   - 对胎位有严格要求（头位/正位最顺，臀位/倒位或横位极易难产）。

2. **卵生 (Oviparous)**：
   - 周期性排出未受精的“空卵”。月经期表现为排出多枚透明卵体，伴随产道扩张感。
   - 孕期主要消耗能量于卵黄积累与蛋壳钙化，而非胚胎本体发育。
   - 产后直接体外独立孵化，环境依赖度高。
   - 对胎位要求极低，除长轴横位外基本无排出阻力。

3. **卵胎生 (Ovoviviparous)**：
   - 退化的结卵过程。未受精卵极易破碎，经期表现为排出大量高度粘稠的胶状物。
   - 前期为卵黄供能发育，在临盆前或宫内破卵，分娩即为能独立活动的幼体。
   - 宫内破卵后，多胎幼体在狭窄空间内可能发生同胞残杀或吞噬弱者。
   - 幼体活动度高，分娩前需极其精准的胎位校正。

4. **胎转卵生 (Metoviviparous)**：
   - 月经表现为高度凝聚的半固体肉质“卵囊”排出，伴随强烈的收缩感。
   - 孕期经历从胎盘供能到卵黄储备的转化，孕晚期卵体巨大且羊水枯竭，有强烈坠胀感。
   - 因卵体接近球形，对胎位敏感度偏低，但偏离产道中轴会导致产力分散。

5. **不定型 (Amorphous)**：
   - 无月经，未受精的能量组织在体内被重新吸收或降解。
   - 胚胎形态变化极大，呈现高度的物种特异性。受孕与着床极不稳定。
   - 分娩模式多样（分裂、重构、排泄等），无通用规律。

## 2. 时间推进与生理生命周期 (Time Passage Engine)

当调用 `bsPassedTime` 工具时，系统会对所有已注册的在场（及以精简模式计算的在野）角色进行生理时钟推进。它是整个插件里计算最为复杂的逻辑，其核心阶段演进如图：

```
[ 无孕状态下的月经周期 ]
  ├── 卵泡期 (9天)
  ├── 排卵期 (2天) ───[ 有精液且判定受精成功 ] ───► [ 进入受精着床期 ]
  ├── 黄体期 (12天)                                         │
  └── 月经期 (5天) ◄────────────────────────────────────────┘ (若着床失败)
                                                           │
                                                           ▼ (着床成功)
                                                     [ 妊娠阶段推进 ]
                                                       ├── 孕早期 (84天)
                                                       ├── 孕中期 (105天)
                                                       ├── 孕晚期 (63天)
                                                       └── 临产期 (28天)
                                                           │
                                                           ▼ (触发分娩机制)
                                                     [ 正式分娩产程 ]
                                                       ├── 第一产程 (开宫口)
                                                       ├── 第二产程 (胎儿分娩)
                                                       └── 第三产程 (供养器排出)
                                                           │
                                                           ▼ (分娩完成)
                                                     [ 产后恢复期 ]
```

### 核心推进细则：

#### A. 受精与着床机制
1. **精残时间**：每次性交后，精液在体内的活性会随着时间逐步衰减。
2. **受精判定**：处于排卵期内时，若体内有精液残留（`sperms` 列表非空），系统会根据各种族的生殖壁垒、精液量计算受精概率。一旦判定受精，计算进入着床期（`fertilizationDays` 递增）。
3. **着床判定**：受精 6 天左右为基础着床等待期。在此期间如果再次遭遇剧烈情压或物理冲击可能会导致受精卵死亡流失。如着床成功，则正式确立妊娠，转入 `孕早期`，否则回归月经周期的 `黄体期`。

#### B. 孕期时间推进
- 每日流逝时，妊娠时间 `pregnantDays` 和有效妊娠时间 `effectivePregnantDays` 递增。
- **妊娠速度倍率**：最终速度受到 `gestationModifierMultiplier` 影响。例如服用特定药物、拥有神圣祝福或诅咒时，倍率可能被设为大于 1（加速）或等于 0（冻结发育）。
- **妊娠阻塞与需求扩容**：系统每日根据代谢累积判定是否有 `blockage`（阻塞）或 `expansion`（扩容）。

#### C. 分娩与产程细节
当 `effectivePregnantDays` 满孕期总长度时，角色会自动进入「产兆前驱」并过渡到「第一产程」。
1. **开指（第一产程）**：宫颈扩张阶段。基础耗时由 `LABOR_STAGE_BASE_HOURS` 定义，且受到胎儿体重的正向影响，以及孕妇的生育次数（`FIRST_STAGE_NATURAL_BIRTH_EXPERIENCE` 提供的缩减倍率）的负向影响。
2. **胎儿下降与分娩（第二产程）**：胎体通过产道并娩出。多胎妊娠时会按顺序（`laborFetusIndex`）一个个娩出。每一胎的推进速度高度依赖胎位角度（`tendencyAngle`）是否为正位。
3. **胎盘娩出与观察（第三产程）**：娩出胎盘或卵泡剥离，随后进入 2 小时（`LABOR_POSTPARTUM_OBSERVATION_HOURS`）的产后密切观察，最后转入「产后恢复期」。
