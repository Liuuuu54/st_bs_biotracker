# 实验性混合池受精：记录拆分与分钟切片一致性

状态：fork 实验实现，**默认关闭**。基于 BioTracker 1.2.1（`78b34f4`）。不自动迁移既有角色，也不重抽既有胎儿。

## 使用入口

在“完整变量”选中卵方，点击“启用实验性混合池”。入口保存启用前后快照；新状态位于 `profile.base.spermPool`，模型标识为 `pooled-v1`。恢复旧模型请还原启用前的完整快照/备份，不直接删除内部字段并保留新模型残量。

模型内部种子、卵阈值和索引保存在状态/楼层快照中，但不送入追踪或主流提示词。胎儿/子女的公开派生审计最多保留受精分钟，不泄漏随机预算。

本分支没有改变默认角色注册、品质分档、物种难度、套子可靠性或身份机制。旧角色默认仍使用既有算法；实验性结果不宣称医学预测。

## 为什么重设计

旧实现按精方聚合残量，同时按接触记录计算受精；面板又使用聚合行。相同物理量的记录拆分会改变衰减预估和来源机会：

- 同族、q=1、24小时：一条40的预览为32.7574%，两条20的预览为28.3847%。
- 同族、q=1、总量20：一条20为22.8800%，两条10为18.2008%。
- 同名后续沉积覆盖聚合行quality，但旧contact仍保留旧quality，导致实际清除与受精暴露采用不同品质口径。
- 原容量比例裁剪也依赖分次：已有20/容量20，加20一次与加10两次，旧来源最终分别为10和8.8889。

目标不是仅把一组概率调高，而是让**同一物理输入的记账拆分**不改变生理结果。实际时间间隔、不同品质、不同相容性、独立避孕事件及不同流入先后仍有意义。

## 数学内核

第 i 条实际体积 V_i、品质 q_i，受体容积倍率 U：

```text
D0 = 10U
s_i = sqrt(q_i)
dV_i/dt = -D0 × (V_i / ΣV) / s_i
```

同品质时整个池每天只流失一份 `10U/sqrt(q)`，不按来源条数倍增。混品质高品质份额相对富集。令 L=ΣV_i s_i，有 dL/dt=-D0；利用单一隐变量求根推进，不依赖通用ODE包。源记录、沉积时间与父系字段始终独立保存，`base.sperms` 仅为按名字派生的物理残量视图。

这是共池清除假设，不是逐细胞独立寿命模型；新物料可能延缓旧份额清除。没有凭空新增每种族绝对寿命参数。

有活性来源的有效量 X_i=V_i sqrt(q_i)/U，X=ΣX_i：

```text
B(X) = min(2, sqrt(X/20))
λ_i = 0.3 × B(X) × X_i/X × 配对系数_i
H = integral Σλ_i dt
P = 1 - exp(-H)
```

X=0时风险为0；移除旧0.5剂量下限，使微量风险连续趋零。配对系数沿用原同族/跨族/胚型难度规则；品质不直接乘最终概率。

同族人类、完整一天：

| 输入 | 新概率 | 一天后实际残量 |
| --- | ---: | ---: |
| 一次20，q1 | 22.7852% | 10 |
| 同刻两次10，q1 | 22.7852% | 10 |
| 两个同参数精方各10，q1 | 22.7852% | 10 |
| 一次20，q0.25 | 13.1877% | 0 |
| 一次20，q4 | 32.7346% | 15 |

标准单源由22.8800%轻微变为22.7852%，不强行维持旧“平均量开根”的窗口误差。

## 容量、失活与既有冲洗

先填空余容量，满池剩余输入x持续混匀、等量流出：旧量乘 `exp(-x/C)`，新增留存 `C×(1-exp(-x/C))`。同种流入v1+v2一次与分两次相同，无需修改已提交的历史批次。容量下降作为单独事件按比例缩容。

`blocked` 在池内表示**已入体但失活**：仍占容量/流失，但没有受精风险。成功阻隔的物料不入池。既有事后避孕继续按真实contact关联待着床胚胎；残量归零的contact保留ID/快照，不因流干丢失因果链接。

上游已有 `bsDrainSperm` 在实验模式按逐条品质快照计算，不再按聚合行最新品质，也不逐条floor丢小数。保留高品质较难排出的既有指数；此处是兼容原工具，不另增主动操作。

## 随机与时间

- 每颗卵有稳定ID、创建分钟、独立固定指数阈值；不每次bsPassedTime重新抽样。
- 固定绝对1分钟网格推进。`1×24小时 / 24×1小时 / 1440×1分钟` 对同一初始状态与随机种子得到相同受精分钟、精方与冻结胎儿数据。
- 在越阈值分钟内定位首次事件，以事件点λ选择精方，再选冻结快照与实际contact；不把累计H_i归一冒充首次事件的父方分布。
- 受精回执出现在本次 `bsPassedTime` 返回的 `conceptionEvents[]` 与message中；不等待整天。仍保留原角色的周期调度、自然排卵/卵衰减规则，没有移植外部引擎的04:00日历。
- 新生卵从当前分钟结束后开始暴露，不领取过去区间。
- 胎儿首次属性使用该卵独立随机通道，避免全局Math.random被其他调用消耗后改写胎父相关结果；其他既有代谢/分娩随机系统不在本PR内重构。

实验模式只接收整数分钟、单次最多31天，在任何角色改变前校验。该边界用于限制逐分钟完整生理推进成本；默认legacy不新增此限制。

## 预测边界

追踪页启用角色用canonical contacts与同一个池积分内核计算单卵24小时静态预览，不再把聚合行送入不同公式。**该数字不预测之后的模型行动/药物，也尚未模拟未来阶段切换与自然新增卵。** 完整周期、孕中孕/嵌套、分娩及多角色长时间交互仍需宿主端场景验证。不要把模块/host fixture测试写成浏览器端到端。
